One line of plain text: the phone battery's last text message to the charger it waited for all day — my entry for [The Battery's Last Text to Its Charger](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab) on [make.fun](https://make.fun).

> hey. 1%. i waited by the outlet all day like a dog at the door and you never came, so i'm dying now. on purpose. tell the wifi i said hi. don't text back.

`main.ts` writes that line to `/output/entry.txt` (154 characters, inside the 1–200 gate) and verifies it byte-for-byte before exiting.
